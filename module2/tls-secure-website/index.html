What if the website used HTTP instead?

Compare the network observer's view with and without TLS.

🔓 Plain HTTP

No TLS handshake and no built-in transport encryption. A network observer can read or alter the HTTP request in transit.

GET /checkout?item=book HTTP/1.1 Host: shop.example

🔒 HTTPS using TLS 1.3

After server authentication and key establishment, the HTTP request and response are encrypted and integrity-protected.

TLS application_data [encrypted, authenticated bytes]

Model limitations: This is an educational visualisation, not a real TLS connection or cryptographic implementation. It models a standard certificate-authenticated TLS 1.3 handshake without 0-RTT, client certificates, or session resumption. In real use, DNS queries, IP addresses, packet sizes and timing may expose metadata; SNI in a typical ClientHello is visible unless protections such as ECH apply. The sample certificate and domains are fictional.
